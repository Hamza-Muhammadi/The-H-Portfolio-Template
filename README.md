# The H Portfolio

A cinematic, responsive portfolio starter by **Ameer Hamza**. Original HTML, CSS and JavaScript. MIT licensed. No install, build step or API key.

**[Live demo](https://ameer-hamza-the-build.muhammadibhai707.chatgpt.site/template-preview/index.html)**

**Start here:** [Setup guide](START_HERE.md) · [AI master prompt](MASTER_PROMPT.md) · [Creator & ManyChat guide](CREATOR_LAUNCH_GUIDE.md)

Open `customize.html`, enter your details and photo, export `portfolio.config.js`, replace that file, then open `index.html`.

- Four entry actions: full portfolio, projects, services and profile.
- Centred four-link navigation; stacked mobile layouts.
- Cinematic intro, interactive project dialogs, Full Story and technical toolkit.
- Three clearly labelled browser demos.
- Keyboard controls, reduced-motion support and safe text rendering.
